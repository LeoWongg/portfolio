About these numbers

This uses Git blame on the portfolio's current source files. A line belongs to the commit that last changed it. Moving backward hides lines changed later; it does not recreate deleted code or every earlier version of a file. Third-party libraries, generated data, images, and videos are excluded.

Dates use each commit's recorded time zone. Commit links open the source changes on GitHub.
